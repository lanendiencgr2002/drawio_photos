# 爆爆狐自动刷怪与数据采集系统使用说明

## 项目概述

爆爆狐自动刷怪与数据采集系统是一个基于计算机视觉和自动化操作的工具，主要用于在游戏中自动识别并刷新特定怪物（爆爆狐）并进行相关数据采集。该系统利用YOLO目标检测技术识别游戏中的怪物，并通过预设的操作脚本执行相应动作。

## 系统组成

系统主要由以下几个部分组成：

1. **自动刷怪主程序**：`自动刷爆爆狐.py`和`自动刷爆爆狐收集数据集.py`
2. **YOLO识别服务**：`/自动标注服务器/`目录下的服务器程序
3. **数据采集与标注工具**：`/tools/`目录下的各种工具
4. **训练数据集**：`/数据集/`和`/yolo_worker/datasets/`目录下的训练数据

## 环境要求

1. Python环境（推荐Python 3.8或更高版本）
2. 必要的Python库：
   - ascript库（用于安卓操作）
   - airscript库
   - ultralytics（YOLO模型）
   - opencv-python (cv2)
   - flask（用于服务器）
   - numpy
   - requests
3. 安卓设备或模拟器（用于运行游戏）
4. 网络连接（用于服务器通信）

## 设置与配置

### 1. YOLO识别服务器设置

1. 进入`自动标注服务器`目录
2. 启动服务器：
   ```
   python 自动标注服务器简单版.py
   ```
   或扩展版：
   ```
   python 自动标注服务器扩展版.py
   ```
3. 服务器默认在端口22234上运行，确保此端口可访问

### 2. 配置主程序

在使用主程序前，需要修改以下配置：

1. 打开`自动刷爆爆狐.py`或`自动刷爆爆狐收集数据集.py`
2. 修改YOLO识别服务URL为您的服务器地址：
   ```python
   yolo识别服务url="http://您的IP地址:22234/recognize"
   ```
3. 根据需要调整以下参数：
   - 场景（1-3）
   - 重试次数
   - 截图次数
   - 截图间隔时间
   - 怪物刷新时间
   - 击杀时间等

## 使用方法

### 自动刷爆爆狐

1. 确保YOLO识别服务器已启动
2. 确保安卓设备或模拟器已连接并且已进入目标场景
3. 运行主程序：
   ```
   python 自动刷爆爆狐.py
   ```
4. 程序将自动执行以下操作：
   - 走到指定位置并寻找怪物血条
   - 识别怪物类型
   - 如果是爆爆狐，则停止执行
   - 如果不是爆爆狐，则击杀并等待刷新
   - 在发生异常时自动重新进入场景

### 数据采集模式

1. 确保YOLO识别服务器已启动

2. 确保安卓设备或模拟器已连接并且已进入目标场景

2. 运行数据采集程序：
   ```
   python 自动刷爆爆狐收集数据集.py
   ```
   
3. 程序将执行以下操作：
   - 走到指定位置并寻找怪物血条
   - 发现怪物后进行截图并上传到服务器
   - 召唤艾比进行战斗
   - 等待击杀完成并收回艾比
   - 等待怪物重新刷新，重复上述过程

## 数据标注与模型训练

### 数据标注

1. 使用`tools/labelimg_autotool开服务版.py`进行数据标注：
   ```
   python 自动标注服务器.py
   python labelimg_autotool开服务版.py
   ```
2. 工具将打开图形界面，您可以加载图片并进行标注
3. 标注时请使用预设的类别：baobaohu（爆爆狐）、dibengbeng、jiaohuogu、zhamaotuo等

### 模型训练

1. 准备好标注数据后，使用`tools/trainyolo.py`进行训练：
   ```
   python trainyolo.py
   ```
2. 训练好的模型将保存在`yolo_worker/runs/`目录下
3. 将最佳模型（best.pt）复制到`自动标注服务器/`目录下，用于识别服务

## 工具集说明

- **yolov8测试.py**：用于测试YOLO模型的识别效果
- **自动标注所有.py**：批量自动标注图片
- **清空文件夹下训练和验证集.py**：清理数据集
- **从数据集中平均的取出图片.py**：均衡采样数据集
- **图片缩短.py**：调整图片大小
- **删除闪退文件.py**：修复labelImg闪退问题

## 常见问题与解决方案

1. **服务器连接失败**
   - 检查网络连接
   - 确认服务器IP地址和端口设置正确
   - 检查防火墙设置

2. **识别准确率低**
   - 增加训练数据量
   - 调整模型参数
   - 使用`yolov8测试.py`测试并优化模型

3. **操作不响应**
   - 检查安卓设备连接
   - 确认游戏界面正常
   - 调整坐标参数以适应不同分辨率

4. **labelImg闪退**
   - 删除 C:\Users\[用户名]\labelImgSettings.pkl 文件
   - 重新启动程序

## 维护与更新

### 模型更新

当游戏更新或识别效果不佳时，需要更新模型：

1. 收集新的数据样本
2. 使用标注工具标注新数据
3. 重新训练模型
4. 更新服务器使用的模型文件

### 参数调整

根据游戏环境变化调整脚本参数：

1. 场景位置和坐标可能需要调整
2. 怪物刷新时间可能会变化
3. 战斗时间和等待时间可能需要优化

## 性能优化建议

1. 使用更高性能的服务器运行YOLO识别服务
2. 优化图像大小和处理流程
3. 减少不必要的截图和网络请求
4. 调整等待时间以适应实际游戏情况
